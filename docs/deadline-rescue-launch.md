## 7日間で確かめること

1. 公開確認、未ログインDL、スマホ実機、Googleへの取り込みを確認。自分の実際の課題3件を入れる。
2. Xで「課題が重なって何から始めるか迷う」場面を投稿。実際のシートの画像を添える。個人の課題名は伏せる。
3. Threadsでは「締切、どこにまとめてる？」と使い方を説明。無関係な投稿への宣伝返信はしない。
4. noteに入力から今日の1件を選ぶまでの短い実例。単なる機能一覧にしない。
5. 使った人に「開けた？自分の課題を入れた？1件着手した？」を確認。感想・個人情報の公開は別途許可を得る。
6. 離脱が大きい1箇所だけ直す。見出しか、取り込み手順か、登録後の最初の操作。
7. 続行判断。まだ人に見られていなければ商品を増やさず、配布先・投稿の切り口を変える。

## 数字の扱い

配布ページからの登録・ログインは `next=/start/rescue` を引き継ぐ。シート内の入口は `/start/rescue`。未ログインならログイン画面を経由し、新規登録への切り替えでも目的地が残る。

既存のページ分析が稼働している場合、管理画面のページ分析で `/start/rescue` の訪問を確認できる。ただしこれは新規登録者数・シート経由人数と同義ではない。ダウンロード人数の自動集計、登録との紐付け、継続率の専用集計はまだ未実装。アクセスログのファイル取得数は重複・botを含み、利用人数と同じではない。

次の開発では、必要最小限のイベント（配布ページ表示、DLクリック、登録完了、初回記録、翌日/7日目の記録、購入成功）を計測する。課題名・本文・メールアドレスは分析イベントに含めない。決済成功はStripe側の確定イベントで集計する。

最初の判断目安は市場平均ではなく実験用の仮置き：

| 指標 | 定義・判断 |
|---|---|
| 表示数 | SNS側で確認。少なければ商品ではなく露出の問題も疑う |
| クリック率 | リンククリック ÷ 投稿表示。1%は仮の目安であり保証ではない |
| 無料DL率 | DLした利用者 ÷ 配布ページ利用者。100訪問で20DLを仮の目安にする |
| 登録率 | シート経由登録者 ÷ DL利用者。まず3〜5人の新規利用を得て行動を観察 |
| 初回記録率 | 登録後24時間以内に勉強を記録した人 ÷ 新規登録者 |
| 翌日継続率 | 登録翌日（日本時間）にも記録した人 ÷ 対象登録者 |
| 7日継続率 | 登録7日後にも記録した人 ÷ 7日経過済みの対象登録者 |
| 商品購入率 | 購入者 ÷ 有料版ページ利用者。まだ販売しないため現時点では対象外 |
| Pro転換率 | 登録後30日以内の初回Pro購入者 ÷ 30日観察済み登録者。永久と月額は分ける |

数人の継続率で改善効果を断定しない。DLだけ多くても、実際の入力・着手・RYUTTER利用が少なければ成功とは扱わない。

## RYUTTERの改善案（提案のみ）

### 1. 最初の記録まで案内する

導線を実装：シートからの登録後は「今日の1件 → 既存タイマー → 実時間・公開先を選択して記録」。既存ユーザーも利用可能。「その他」の「今日の1件」から再訪できる。公開先は未選択から開始し、選択と保存操作なしに投稿しない。グループ・称号など既存の楽しみはそのまま使える。全機能の説明を最初に強制しない。

入力途中の本文・時間はこの端末にユーザー別の下書きとして保存する（7日以内の下書きを復元、記録成功時に削除）。シートの中身の読取りや自動送信はしない。この画面の記録は通知なし。本文の見える範囲と、学習時間がプロフィール等に反映される点は保存前に表示する。

### 2. 課金は値下げより、用途が伝わることを優先

現在の料金表では、無料はタスク5件・教材3冊・グループ作成1個、月額Proは240円。Proには試験逆算計画、分析、AI、着せかえ等がある。

当面240円は維持し、「試験までに今週何をやるか決める」「先週と比較して勉強を調整する」の実画面をProページに載せる。未検証の効果や「人気」表示で売るより、得られる機能を具体的に示す。初回記録前から課金を強く迫らない。

### 3. 永久500円を通常価格にしない

月額240円の約2.1か月分で永久利用となるため、追加販売を続けると継続的な運営費を賄いにくい。先着30名は初期応援企画として区切る。既存購入者への約束は守り、勝手に期間制限や機能削除をしない。

月額の継続率が見えるまでは年額・複数プランを急いで増やさない。学生向けには、需要を確認してから「試験期1か月の買い切り利用・自動更新なし」を候補にする。決済手段の審査と対応は別途確認する。

### 4. AIの原価を把握する

プランごとにAI機能の利用回数と外部費用を把握する。制限を変更する場合は購入時の約束と説明を確認する。標準カード決済の手数料以外にもBilling、税、ホスティング等があり得るので、「240円がそのまま利益」と計算しない。

Stripeの現行料金：https://stripe.com/jp/pricing

### 5. 商品とProの役割を分ける

- 無料シート：今日の課題を整理する。登録しなくても役立つ。
- 将来500円版：1学期分の科目別・週別整理など、ファイル単体で完結する上位版。欲しい人の反応を見てから作る。
- 将来980円版：試験管理・計画の立て直しまで。500円版が使われてから検討。
- Pro：RYUTTER上で継続的に使う計画・分析・カスタマイズ。商品購入にPro加入を強制しない。

テンプレート購入者全員に永久Proを付ける、といった売り方はしない。
